# SrvDB examples gallery

Twelve small, complete programs, each in its own folder with one script
and a README. They run fully offline on scikit-learn's bundled datasets
(digits, `make_blobs`) or on synthetic data generated by the script, and
every number they print or plot is measured by that run. Each script
starts by printing the CPU, OS, Python and library versions and the git
commit, so a result can be traced to what produced it.

| # | Example | Shows | Chart |
|---|---------|-------|-------|
| 01 | [Getting started](01_getting_started/) | create, add, search, `where=`, reopen, delete | none |
| 02 | [Index modes](02_index_modes/) | flat, HNSW, IVF, SQ8, PQ, RaBitQ compared | recall, QPS, memory per mode |
| 03 | [Filtered search](03_filtered_search/) | `where=` at 1 to 100 % selectivity | recall and latency vs selectivity |
| 04 | [Hybrid search](04_hybrid_search/) | vector, BM25 `text=`, and both fused | quality per method and query kind |
| 05 | [Graph links](05_graph_links/) | `db.link`, `expand=` | answer found with and without links |
| 06 | [Clustering](06_clustering/) | KMeans + PCA, SrvDB finds representatives | PCA scatter of clusters |
| 07 | [Classification](07_classification/) | k-NN on SrvDB vs scikit-learn | accuracy and latency |
| 08 | [Deduplication](08_deduplication/) | near-duplicates by cosine threshold | precision and recall vs threshold |
| 09 | [Local RAG](09_local_rag/) | retrieval over the SrvDB docs, offline | hit@k for k = 1..5 |
| 10 | [Memory budget](10_memory_budget/) | `index="auto"`, `memory_mb`, `memory_report()` | memory and recall as data grows |
| 11 | [LangChain / LlamaIndex](11_frameworks/) | the optional adapters | adapter latency vs direct calls |
| 12 | [Edge / small memory](12_edge/) | RaBitQ bits, `certify=`, `deadline_ms=`, `rebuild_checksums` | memory vs recall |

A larger, domain-specific example lives in
[`examples/theorem_proving`](../theorem_proving/): premise retrieval for
Lean proofs with vector, keyword and hybrid search plus dependency links.

## Run

From the repository root, with SrvDB installed (`pip install srvdb`, or
`maturin develop` in a checkout):

```bash
pip install -r examples/gallery/requirements.txt
python examples/gallery/02_index_modes/index_modes.py          # one example
python examples/gallery/run_all.py                             # all, full size
python examples/gallery/run_all.py --fast                      # all, small (CI)
python examples/gallery/run_all.py --only 03 08                # a selection
```

Every script accepts `--fast` (small sizes, a few seconds) and
`--out DIR` (where charts go; default `examples/gallery/output/`, which
is gitignored). `tests/python/test_examples_gallery.py` runs
`run_all.py --fast` and is skipped when the requirements are missing.

## Reading the numbers

Timings and throughput depend on the machine, the Python version and what
else is running; recall, accuracy and precision depend on the dataset.
The synthetic datasets are easy to reproduce but easier than real
embeddings, so treat the results as a demonstration of how to measure,
then measure on your own data. The charts are a monochrome rendering of
the printed table, never of numbers from elsewhere.

## Dependencies

`requirements.txt` lists scikit-learn, NumPy, pandas and matplotlib with
their licences. They are needed by the examples only; the `srvdb` package
depends on none of them. Example 11 additionally uses the
`srvdb[langchain]` and `srvdb[llamaindex]` extras and skips a framework
that is not installed.
