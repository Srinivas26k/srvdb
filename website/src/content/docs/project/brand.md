The SrvDB mark is a **cubist imperial eagle**: the sharpest eye in nature,
built from flat planes. The planes stand for embeddings; the pupil sits on the
edge of the iris, the point on the unit circle that cosine search compares.

| Colour | HEX |
|--------|-----|
| Imperial navy | `#1B2A4A` |
| Ink | `#0F1A30` |
| Crimson | `#C8102E` |
| Gold | `#F2B134` |
| Austerlitz cream | `#F6E7C8` |

The wordmark is Cinzel Bold (SIL Open Font License), outlined.

Logo files, usage rules and the build script:
[assets/brand](https://github.com/Srinivas26k/srvdb/tree/master/assets/brand).
The Apache-2.0 licence covers the code, not the SrvDB name or logo.
